HOW THE CODE WORKS (for viva)
-----------------------------
- The graph is stored as an adjacency list: a dictionary where each
  vertex maps to a list of its neighbours.
- add_edge(u, v) adds the edge in both directions because the graph
  is undirected.
- DFS is recursive:
      visit the current vertex,
      mark it visited,
      recursively visit every unvisited neighbour.
  DFS uses the call stack (or an explicit stack).
- BFS uses a queue (collections.deque):
      put the start vertex in the queue,
      remove a vertex from the front,
      add all unvisited neighbours to the back,
      repeat until the queue is empty.
- BFS visits vertices level by level.

Complexity for a graph with V vertices and E edges:
       DFS: O(V + E) time, O(V) space
       BFS: O(V + E) time, O(V) space


VIVA QUESTIONS AND SHORT ANSWERS
--------------------------------
Q1. Difference between DFS and BFS?
A1. DFS goes as deep as possible before backtracking and uses a stack.
    BFS visits all neighbours at the current level first and uses a
    queue. BFS finds the shortest path in an unweighted graph; DFS
    does not guarantee the shortest path.

Q2. Why is DFS called recursive?
A2. Because it calls itself on each unvisited neighbour. The recursion
    stack stores the path being explored.

Q3. Which data structure does BFS use?
A3. A FIFO queue. In this program it is collections.deque.

Q4. Time and space complexity of DFS/BFS?
A4. O(V + E) time and O(V) extra space for both, using an adjacency
    list.

Q5. What is an undirected graph?
A5. A graph where an edge between u and v can be travelled in both
    directions. add_edge adds u->v and v->u.

Q6. Can DFS get stuck in an infinite loop?
A6. On a graph with cycles, yes, if visited vertices are not marked.
    The visited set prevents this.

Q7. What is the difference between a graph and a tree?
A7. A tree is a connected acyclic graph. A graph may have cycles and
    may be disconnected. DFS/BFS work on both.

Q8. How would you make this directed?
A8. Remove the reverse edge line in add_edge (the line that appends u
    to graph[v]).


COMMON MISTAKES
---------------
- Typing "S A" on one line. Enter S, press Enter, then A, press Enter.
- Starting DFS/BFS with a vertex that was never added. Add edges first.
- Expecting the same traversal order every time. It depends on the
  order of neighbours in the adjacency list.
- If the program waits, it is asking for the next input value.
