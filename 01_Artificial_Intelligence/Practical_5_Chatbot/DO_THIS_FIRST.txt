STEP-BY-STEP IN THE UBUNTU LAB (RESTAURANT CHATBOT)
---------------------------------------------------
1. Open Terminal (Ctrl+Alt+T).
2. Find the pendrive name:

       ls /media/$USER

3. Go to the code folder (replace MYUSB):

       cd "/media/$USER/MYUSB/01_Artificial_Intelligence/Practical_5_Chatbot/code"

4. Run:

       python3 main.py

5. Type a message and press Enter. Try:

       menu
       what is the cost
       contact
       book a table
       hours
       date
       how are you
       exit

6. To run the same conversation automatically:

       python3 main.py < ../sample_input.txt

7. To stop at any time, type:

       exit

   (or press Ctrl+C).

HOW THE CODE WORKS (for viva)
-----------------------------
This is a rule-based / retrieval-based chatbot. It does not use a
trained machine-learning model.

- The program reads the user's message and converts it to lowercase.
- It checks for keywords with the "in" operator:
      if "menu" in user_input: ...
      elif "cost" in user_input or "price" in user_input: ...
- The first matching rule produces the response.
- If no rule matches, a fallback response is printed.
- "exit", "quit" or "bye" ends the loop.
- datetime is used for the date/time response.

The investment version works the same way, with keywords such as
savings, FD, mutual funds, stocks, risk, tax and time horizon.

The NLTK alternative uses regular-expression patterns:
      Chat(pairs, reflections)
      chat.converse()
It is still pattern matching, not a neural network. It needs:

      pip3 install nltk


VIVA QUESTIONS AND SHORT ANSWERS
--------------------------------
Q1. What is a chatbot?
A1. A software application that simulates a conversation with a user
    through text or voice.

Q2. What are the types of chatbots?
A2. Text-based and voice-based; rule-based (retrieval) and
    machine-learning / generative chatbots. This practical builds a
    rule-based text chatbot.

Q3. How does this chatbot understand the user?
A3. It performs keyword matching on the lowercased input string. It
    does not parse grammar or understand meaning.

Q4. What is NLP?
A4. Natural Language Processing: the field of AI concerned with
    enabling computers to understand, interpret and generate human
    language.

Q5. What are the limitations of a rule-based chatbot?
A5. It only handles phrases anticipated by the programmer. It cannot
    generalize to unseen wording and has no real language
    understanding.

Q6. How would you improve it?
A6. Use intent classification (TF-IDF + classifier), word embeddings,
    or an LLM API. Add context tracking and a larger knowledge base.

Q7. What is NLTK?
A7. The Natural Language Toolkit, a Python library for NLP tasks such
    as tokenization, stemming, tagging and chatbot pattern matching.

Q8. What is the difference between a rule-based and an ML chatbot?
A8. Rule-based: hand-written if/else or regex rules. ML: learns
    patterns from training data and can generalize to new phrasing.

Q9. Why is input converted to lowercase?
A9. So "Menu", "MENU" and "menu" all match the same keyword.

Q10. How does the program end?
A10. The while loop breaks when the input contains "exit", "quit" or
     "bye".

Q11. What is a fallback response?
A11. The default reply when no rule matches, e.g. "I'm sorry, I didn't
     understand that."

Q12. Is this chatbot using AI?
A12. It is a simple symbolic AI / rule-based system. It does not learn
     from data.


COMMON MISTAKES
---------------
- Running alternative_nltk_chat.py without installing NLTK. Use
  main.py if the lab has no internet.
- Typing "Exit" with a capital E: it still works because the input is
  lowercased.
- Expecting the chatbot to answer arbitrary questions. It only knows
  the programmed keywords.
- For the NLTK version, if pip install fails, do not waste time; use
  main.py.
