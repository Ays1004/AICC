PRACTICAL 1 - DFS AND BFS
-------------------------
Aim:
To implement Depth First Search (DFS) and Breadth First Search (BFS)
algorithms for traversing an undirected graph using a recursive
approach.

Algorithm - DFS:
1. Start at the given vertex and mark it visited.
2. Print the vertex.
3. For every neighbour of the vertex:
   a. If the neighbour is not visited, call DFS recursively.
4. Stop when all reachable vertices are visited.

Algorithm - BFS:
1. Create an empty queue and a visited set.
2. Mark the start vertex visited and enqueue it.
3. While the queue is not empty:
   a. Dequeue a vertex and print it.
   b. For every unvisited neighbour, mark it visited and enqueue it.
4. Stop when the queue is empty.

Conclusion:
Thus, DFS and BFS were implemented successfully on an undirected
graph. DFS explores depth-first using recursion/stack, while BFS
explores level-by-level using a queue. Both have time complexity
O(V + E) for V vertices and E edges.

PRACTICAL 2 - A* FOR 8-PUZZLE
-----------------------------
Aim:
To solve the 8-puzzle problem using the A* search algorithm with the
misplaced-tiles heuristic.

Algorithm:
1. Define the start state and the goal state.
2. Put the start state in the OPEN list with g = 0 and
   f = g + h.
3. While OPEN is not empty:
   a. Remove the state with the smallest f.
   b. If it is the goal, reconstruct and print the path; stop.
   c. Put it in CLOSED.
   d. Generate its children by moving the blank up/down/left/right.
   e. For each child not in CLOSED, compute g, h and f and add it to
      OPEN.
4. If OPEN becomes empty, no solution exists.

Conclusion:
Thus, the 8-puzzle was solved using A*. The heuristic
h(n) = number of misplaced tiles is admissible, so A* finds an
optimal solution. The program found the goal in 3 moves for the
sample initial state.

PRACTICAL 3 - GREEDY SEARCH
---------------------------
Aim:
To implement a greedy search algorithm for selection sort and the
job scheduling problem.

Algorithm - Selection Sort:
1. For i = 0 to n-2:
   a. Assume the minimum is at index i.
   b. Compare with every element j > i and update the minimum index.
   c. Swap the minimum element with the element at i.
2. The array is sorted.

Algorithm - Job Scheduling:
1. Read each job's id, deadline and profit.
2. Sort the jobs in decreasing order of profit.
3. Find the maximum deadline and create an array of free slots.
4. For each job, find the latest free slot before its deadline.
5. If a slot is free, schedule the job and add its profit.
6. Print the scheduled job ids and the total profit.

Conclusion:
Thus, the greedy approach was implemented successfully. Selection
sort repeatedly selects the minimum remaining element (O(n^2)).
Job scheduling sorts by profit and places each job in the latest
free slot before its deadline, giving the maximum total profit for
unit-time jobs.

PRACTICAL 4 - N-QUEENS
----------------------
Aim:
To solve the n-queens constraint satisfaction problem using
backtracking and branch-and-bound pruning.

Algorithm:
1. Start with row i = 0.
2. For each column j from 0 to n-1:
   a. Check whether column j and both diagonals are free.
   b. If free, place a queen and mark the column and diagonals.
   c. Recursively place the queen in row i + 1.
   d. If the recursion fails, remove the queen and unmark the
      column/diagonals (backtrack).
3. If i == n, a complete solution is found.
4. If no column works, return false.

Conclusion:
Thus, the n-queens problem was solved using backtracking with
branch-and-bound pruning. The column and diagonal arrays make each
safety check O(1), and invalid branches are abandoned early. The
program produced valid boards for 4 queens and 8 queens.

PRACTICAL 5 - CHATBOT
---------------------
Aim:
To develop an elementary rule-based chatbot for a customer
interaction application (restaurant/investment advice).

Algorithm:
1. Display a welcome message.
2. Read the user's message and convert it to lowercase.
3. Match keywords in the message against the rule set.
4. Print the response for the first matching rule.
5. If no rule matches, print a fallback response.
6. If the message contains exit/quit/bye, stop.
7. Repeat from step 2.

Conclusion:
Thus, an elementary chatbot was developed using keyword/pattern
matching. It responds to predefined customer queries and ends on
exit. The limitation is that it cannot understand unseen phrasing
because it does not learn from data.

PRACTICAL 6 - EXPERT SYSTEM
---------------------------
Aim:
To implement a rule-based expert system for medical diagnosis using
a knowledge base, an inference engine and a user interface.

Algorithm:
1. Define the knowledge base as symptom-to-disease rules.
2. Ask the user yes/no questions for each symptom.
3. Store the answers as facts.
4. For every symptom that is present, apply the corresponding rule
   and add the disease to the diagnosis list.
5. Display all diagnosed diseases.
6. If no rule matches, advise the user to consult a doctor.

Conclusion:
Thus, a rule-based expert system was implemented successfully. It
uses forward chaining: user-provided symptoms are facts, and the
inference engine derives the possible diseases. The knowledge base
is separate from the inference logic, so new rules can be added
easily.
