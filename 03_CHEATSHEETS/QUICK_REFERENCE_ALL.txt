CLOUD COMPUTING
===============
P1 - AWS EC2
    Browser: https://aws.amazon.com/console/
    Then follow Practical_1_AWS_EC2/DO_THIS_FIRST.txt
    SSH: chmod 400 lab-key.pem
         ssh -i lab-key.pem ubuntu@<PUBLIC_IP>

P2 - KVM (Ubuntu terminal)
    sudo apt update
    sudo apt install -y cpu-checker
    sudo kvm-ok
    sudo apt install -y qemu-kvm libvirt-daemon-system libvirt-clients \
                        virt-manager virtinst bridge-utils
    sudo systemctl enable --now libvirtd
    sudo usermod -aG libvirt,kvm $USER
    newgrp libvirt
    sudo virsh net-start default
    sudo virsh net-autostart default
    virsh list --all
    virt-manager

P3 - Salesforce Apex
    Browser: https://login.salesforce.com
    Developer Console -> File -> New -> Apex Class
    Name: AccountService
    Paste code/AccountService.cls, Ctrl+S
    Ctrl+E -> paste code/execute_anonymous.apex -> Execute

P4 - Salesforce custom app
    Browser: https://login.salesforce.com
    Setup -> Object Manager -> Create custom objects
    Setup -> Tabs -> create tabs
    Setup -> App Manager -> New Lightning App
    Open the app from App Launcher
