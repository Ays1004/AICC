WHAT WAS EXCLUDED
-----------------
The large Notes folders, question papers, handouts, write-ups and
assignment PDFs were not copied. This pendrive is meant for the
practical lab, so only code, instructions, sample input/output and
the remaining reference guides are included.

WHAT WAS CHANGED
----------------
The code is based on the repositories, with small lab-friendly changes:

1. Practical 1 (DFS/BFS)
   - clearer prompts; one vertex per line
   - main() is called only when the file is run directly

2. Practical 3 (Greedy)
   - the numbers list is cleared before new input, so selection sort
     can be run twice from the menu without mixing old values
   - main() is called only when the file is run directly

3. Practical 5 (Chatbot)
   - added investment_chatbot.py because the handout problem statement
     asks for an investment-suggestion chatbot, while the repository
     main code is a restaurant chatbot

4. Practical 6 (Expert System)
   - the memory question was inverted in the repository code; it now
     asks "Do you forget things often?" so YES means the symptom is
     present
   - spelling of Alzheimer's corrected

The folder 01_Artificial_Intelligence/_REPO_ORIGINAL contains the
exact files from the AI repository, without these changes.
